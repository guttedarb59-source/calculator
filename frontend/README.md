# Simple Calculator

A simple full-stack calculator application built using React, Node.js, Express.js, and MongoDB Atlas.

## Technologies Used

- **Frontend:** React.js, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Tools:** VS Code, Git, GitHub

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Calculation history stored in MongoDB Atlas

## Project Structure

```text
calculator/
├── frontend/
│   └── src/
├── backend/
│   ├── server.js
│   └── .env
└── README.md
```

## How to Run

### Backend

```bash
cd backend
npm install
node server.js
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
